---
title: "Health check endpoints: GET / and GET /health"
sidebarTitle: "Health"
description: "GET /health returns the API readiness status. Used by Docker Compose healthchecks to determine when the api service is ready to accept traffic."
---

CommunityLab exposes two lightweight health check endpoints registered under the `Health Check` tag. They require no authentication, accept no parameters, and return a small JSON object. Docker Compose uses `GET /health` as its readiness probe — the `api` service is not marked healthy until this endpoint returns `200 OK`, which prevents the frontend and worker containers from starting before the API is ready. The nginx proxy separately exposes a `GET /healthz` route on port 8080 for its own liveness check.

---

## GET /

The root endpoint confirms that the FastAPI process is running and reachable.

**Request**

```bash
curl http://127.0.0.1:8080/
```

**Response `200 OK`**

```json
{
  "status": "online",
  "mensaje": "El motor Backend de CommunityLab está operativo y seguro. 🚀"
}
```

| Field | Type | Description |
|---|---|---|
| `status` | string | Always `"online"` when the process is up |
| `mensaje` | string | Human-readable confirmation message |

---

## GET /health

The dedicated readiness endpoint used by Docker Compose `healthcheck` directives and by any external monitoring that needs a minimal, stable path to probe.

**Request**

```bash
curl http://127.0.0.1:8080/health
```

**Response `200 OK`**

```json
{
  "estado": "ok",
  "servicio": "communitylab-api"
}
```

| Field | Type | Description |
|---|---|---|
| `estado` | string | Always `"ok"` when the service is ready |
| `servicio` | string | Service identifier — always `"communitylab-api"` |

---

## Nginx proxy health

The nginx reverse proxy that forwards traffic from port **8080** to the FastAPI service on port **8000** has its own liveness endpoint at:

```
http://127.0.0.1:8080/healthz
```

<Note>
  `/healthz` is served by nginx itself and does **not** hit the FastAPI process. It responds `200 OK` as long as nginx is running, regardless of whether the Python API is up. Use `GET /health` when you need to verify that FastAPI is ready to handle requests.
</Note>
